# device_manager
<img src="docs/img/badges.svg">

Network device inventory module for the Velty ecosystem: tenant-scoped registry of computers,
printers, servers and other equipment, their network interfaces (MAC + IP), the zones they sit in and
how much of the network each may use. It is the source of truth `veltylabs/network_manager` applies to
the router, through `webtyp.com/network`.

## Ops

| Op | Action | Resource |

| `upsert_device` | create/update | `device` |

| `list_zones` | read | `zone` |

| `list_network_interfaces` | read | `network_interface` |
| `save_network_interface` | create/update | `network_interface` |
| `delete_network_interface` | delete | `network_interface` |

## Quick Start

```go
import devicemanager "github.com/veltylabs/device_manager"

dm, err := devicemanager.New(db, devicemanager.Deps{
    IDs:       idGenerator,    // model.IDGenerator, required
    Publisher: eventPublisher, // events.Publisher, optional
})
dm.MountOperations(reg)    // router.OperationRegistry
view := dm.NewView(caller) // router.Caller -> view.Presenter (also NewZoneView, NewNetworkInterfaceView)

// webtyp.com/network boundary: the hosts the router must enforce, and the
// one-time import of hand-made router configuration.
hosts := devicemanager.NetworkHosts{Devices: dm, TenantID: tenant} // network.HostSource + network.HostImporter
```

## View and demo

The module exports three screens under `ui/`: `ui.Browser` (Equipos), `ui.ZonesBrowser` (Zonas) and
`ui.InterfacesBrowser` (Interfaces de red), all `(caller, ids, tenantID)`. The zone and device selects
are filled when the screen is activated.

Demo data can be seeded using `seed.Load(m, tenantID)`.

Run `webtyp` at the repository root to open the demo — in-browser, in-memory, no login.

## Key files

| File | Purpose |
|---|---|
| `model.go` | `Device`, `Zone`, `NetworkInterface` definitions, errors, event topics |
| `kinds/` | Closed-option field kinds (device type, access) — their own package for ormc |
| `model_orm.go` | Generated by `ormc` — do not edit |
| `module.go` | `Module`, `New`, device service methods |
| `zone.go`, `interface.go`, `ip.go` | Zones, interfaces (MAC/IP rules, IP auto-assignment), IPv4 helpers |
| `network.go` | `NetworkHosts`: `webtyp.com/network` `HostSource` + `HostImporter` |
| `ops.go` | `router.OperationModule` — `MountOperations` + handlers |
| `view.go` | `NewView`, `NewZoneView`, `NewNetworkInterfaceView` |
